# Governance

This repository holds the governance documents for the Open Cybersecurity Schema Framework (OCSF), a Series of LF Projects, LLC.

## Charter

- [OCSF Technical Charter](OCSF%20Technical%20Charter.pdf): adopted November 18, 2024. It sets out the responsibilities and procedures for technical contribution to, and oversight of, the project. Under the charter, contributors also comply with the [LF Projects policies](https://lfprojects.org/policies/).
